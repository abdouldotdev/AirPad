# Vidéo de démonstration pour App Review

Jointe à la soumission via `review_attachments_upload`. Durée visée : **45–70 s**.

## Ce que la vidéo doit prouver

Une seule chose, mais elle est décisive : **le Mac obéit réellement à l'iPhone.**
Le reviewer n'a pas de Mac appairé ; sans cette preuve il conclut « l'app ne fait
rien » et rejette. Tout le reste (jolis écrans, transitions) est superflu.

Donc le plan doit montrer **les deux appareils dans le même cadre**, sans coupure,
pour qu'on voie que le curseur bouge au moment où le doigt bouge.

## Découpage

| # | Durée | Ce qu'on voit | Ce que ça prouve |
|---|---|---|---|
| 1 | 0–6 s | Le Mac, app AirPad ouverte : QR code, IP, code d'appairage, « Waiting for connection… » | Le compagnon Mac existe et attend |
| 2 | 6–16 s | L'iPhone : écran d'appairage → scan du QR **ou** saisie manuelle IP + code | Comment on appaire |
| 3 | 16–22 s | Le Mac passe à « Connected » / l'iPhone affiche « Connected » | La liaison s'établit |
| 4 | 22–40 s | **Plan large des deux appareils.** Le doigt glisse sur le trackpad de l'iPhone, le curseur du Mac suit. Un clic ouvre un dossier | **Le cœur : le contrôle fonctionne** |
| 5 | 40–52 s | Toujours en plan large : frappe au clavier de l'iPhone, le texte apparaît sur le Mac | Le clavier (fonction payante) fonctionne |
| 6 | 52–60 s | L'iPhone : Réglages → « Get AirPad Pro » → le paywall, avec les deux formules | L'achat intégré est honnête et visible |

## Si tu filmes toi-même (téléphone posé, Mac derrière)

Le plus simple et le plus convaincant :

1. Pose ton iPhone à plat devant l'écran du Mac, les deux visibles dans le cadre.
2. Filme avec un **deuxième appareil** (iPad, autre téléphone) en une seule prise.
3. Ouvre AirPad sur le Mac (menu bar → *Start Pairing*) : le QR s'affiche.
4. Sur l'iPhone : appairage, puis **bouge le doigt lentement** — l'important est
   qu'on voie la correspondance doigt ↔ curseur.
5. Fais un clic, un défilement à deux doigts, puis tape quelques lettres.
6. Termine sur le paywall.

Pas de montage, pas de musique, pas de texte incrusté : App Review veut une preuve,
pas une publicité. Une seule prise continue vaut mieux qu'un montage soigné, parce
qu'elle exclut le trucage.

Format : MP4 ou MOV, ≤ 500 Mo. Dépose le fichier n'importe où et donne-moi le
chemin ; je le joins à la soumission.
